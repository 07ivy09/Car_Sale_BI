# 🚗 Cars Sales Dashboard | Power BI

## 📌 Project Overview
This project presents an **interactive Cars Sales Dashboard** built using **Power BI**, designed to analyze **sales performance, pricing trends, dealer performance, and regional insights**.  
The dashboard supports **executive decision-making** by providing both **high-level KPIs** and **transaction-level drill-downs**.

---

## 🎯 Business Objectives
- Monitor **Year-to-Date (YTD) sales performance**
- Track **average pricing trends**
- Analyze **cars sold across dealers, regions, and body styles**
- Enable **detailed transaction-level analysis**
- Support **filter-based exploration** for operational insights

---

## 📊 Dashboards Included

### 1️⃣ Overview Dashboard
A high-level summary for leadership and stakeholders.

**Key Insights Provided:**
- YTD Total Sales, Avg Price, and Cars Sold
- Month-to-Date (MTD) comparison
- Weekly sales trend analysis
- Sales distribution by:
  - Body Style
  - Body Colour
  - Dealer Region (Map)
- Company-wise sales performance table

### 2️⃣ Details Dashboard
A granular view for operational and analytical users.

**Key Features:**
- Transaction-level sales table
- Customer, dealer, company, model, and color details
- Conditional formatting for sales values
- Dynamic filtering for deep analysis

## 💡 Key Business Insights
- Certain body styles contribute disproportionately to total revenue
- Dealer performance varies significantly by region
- Average price trends impact overall revenue growth

## 🚀 How to Use
1. Download the `.pbix` file from the repository
2. Open in **Power BI Desktop**
3. Interact using slicers and filters
4. Drill down from Overview → Details for deeper insights
